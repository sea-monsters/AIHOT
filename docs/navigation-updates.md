# 页面内容更新提示

桌面侧栏全部 12 个实际页面入口，以及手机首页/进展/日报与「更多」内对应入口，使用统一暖橙点。手机「更多」是其中未读页面的汇总，打开「更多」本身不会清除子页面更新。论文情报也可从手机「更多」进入。

## 内容与阅读口径

- `packages/contracts/src/navigation-updates.ts` 是稳定页面键、标签、路径和静态内容版本的唯一注册表。路径精确匹配；论文详情和日报历史页不等同于其父级概览。
- 首次启用，以当次实际读取的版本建立安静基线，不把所有历史内容都标新。有有效旧日志已读时间时迁移它；完整 ISO（秒、Z 或毫秒）与旧分钟格式均可识别，损坏值视为未知。
- `/` 与 `/research` 共用论文来源，阅读记录独立。新论文或题名、摘要、作者、关键词、来源日期、解释性分数等实际字段变化，推进对应内容版本。纯 last_seen、metadata_checked_at、采集心跳、页面计算时间不推进版本。
- `/all` 的默认无筛选概览读取论文库；`/hot` 保留 v37 全量关键词图，论文与已保存有效评估内容更新影响其版本；只切换显示、悬停或重算相同内容不算更新。
- `/daily` 追踪最近归档的实际内容/状态与已生成段落；页面版本带有最近归档日期。历史日报不能确认另一天的新报告。未读日报入口直接指向该最近归档，即使今天尚未生成。
- `/starred` 只追踪本账户收藏集合与其中论文内容变化；单篇已读/未读不影响收藏更新版本。
- `/settings` 追踪本账户实际配置/偏好与「是否配置凭证」变化；不记录凭证内容，不因测试时间、用量、运行日志或无变化保存反复提示。
- `/topics`、`/agent`、`/about`、`/feedback` 等静态内容使用各自 `version`。只有该页真实内容或解释口径变动时才递增其版本；共用运行说明的页面需分别递增相关入口。每次代码维护应检查此注册表。不能用全站 release 数或构建时间给所有页面强制造新。
- 更新日志使用自身 `latestVersion` 的完整 UTC 时间作为版本，按 UTC+08 日期展示。最新条目实际进入视口且展开时才确认；旧日期锚点或隐藏最新条目的类型筛选不会误清除它。

## 成功加载与并发

真实页面读取前后各读取一次内容版本；两端相等才随成功的数据返回可确认的快照。读取途中更新时不确认，下一次加载再建立稳定快照。元数据读取不采集、不调用模型。失败、预加载、hover、SSR、导航开始、隐藏标签页、prerender 均不确认。

挂载后还须在前台、下一绘制帧仍可见；快速导航清理会取消该帧。只确认该次加载版本，绝不把之后检测到的新版一起标为已读。默认无筛选第一页是「看过该页最新概览」的口径，并非逐篇阅读；查询、过滤、第二页与指定研究进展日期不会确认默认概览。打开日报或进展不会批量标记论文已读。

数据库 `navigation_content` 用触发器维护单调版本；`navigation_seen` 按可信所有者 ID 与有限页面键保存已读版本/开关。确认用 `max`，旧标签页晚到的请求不能回退已读状态或吞掉更高的未读版本。持久状态不依赖浏览器存储；浏览器只使用无内容 storage 事件提示另一标签页重新读取。还在前台焦点、路由变化、每分钟进行轻量读取。存储禁用时仍可通过焦点和前台检查同步。

## 设置与安全

「网站设置 → 页面更新提示」可逐页关闭/开启。关闭仅隐藏点，不抹掉未读版本；关闭期间出现新内容，重新开启后仍会提示。该页若正常打开读到新版，即使关闭提示也会保存已读。写入失败会回滚乐观消点，并在设置内提供重试说明。

所有账户状态读写经过所有者验证；写入还需同源、JSON、自定义请求头与 Fetch Metadata 校验。未知键、额外字段、超量请求和未来版本被拒绝。不修改模型、调度、论文 read/favorite、分享权限；新增表与触发器是追加的 Drizzle 迁移。
