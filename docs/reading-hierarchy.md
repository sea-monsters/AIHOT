# 栏目阅读层级与分隔

2026-10-07（UTC+08）维护。保持暖橙纸色、无阴影、现有容器与右栏框架。

## 分隔线只有一个归属

- 页签后紧邻统计区：保留页签底线，移除统计区顶线
- 日报日期标题后紧邻统计区：保留标题底线，移除统计区顶线
- 论文统计区后紧邻跨库检索：保留统计区底线，移除检索区顶线
- 设置服务列表后紧邻下一栏目：保留服务列表底线，移除下一栏目顶线
- 右栏月历 / 筛选卡片后紧邻说明：保留卡片边框，移除说明的重复顶线；说明条目之间仍有一条分隔
- 空态用标题与留白组织；父级列表有边线时只保留父级，空态本身不重复画上下边框
- 日报 / 周报主题组只保留组顶线；论文列表仍用条目底线。溯源折叠属于论文内部，用间距和标签组织，不再嵌套一条横线
- 表格网格、输入框、焦点描边、图表和主题导航卡片边界均保留

规则使用明确组件和相邻关系，不以全局 `section`、`hr` 或任意后代选择器删除边框。

## 文字与真实语义

- 页面和栏目标题保留原有字号；日志条目标题桌面18px、窄屏17px，650字重
- 日志正文从共享约15.5px缩到14px，1.75行高；原本结构化的 body 数组逐项渲染为 ul/li，适度缩进。单条中原有加粗仍保留，不改变正文内容
- 日志时间/来源保持次级13px左右；上游提交为有序列表，归属到该更新条目中
- 解释性折叠面板正文14px / 1.75，其真实 h3 为15px / 650字重；RSS/MCP说明段落15px / 1.8并在其标题下轻度缩进
- 普通段落不自动变成标题，不添加生硬的 `#` 原字符，不全局缩小摘要或文章正文
- 现有 Markdown h2/h3/h4 原生标题保持；嵌套列表保留 ul/ol/li 父子关系，二/三级无序列表用空心圆/方形，有序列表用字母/罗马数字。混合列表、编号起点与缩进续行按结构渲染
- 代码、表格、引用及链接规则独立，不让列表排版规则影响这些元素

## 回归边界

真实已登录云端浏览器先检查首页、日报、论文情报、研究进展、热点、主题、收藏、更新日志、设置与运行说明，然后做同页面对照、窄屏、缩放和折叠/焦点检查。个人状态、论文库、调度、模型与采集配置不由此改动。

语义回归覆盖日志列表与 hidden/aria-controls、Markdown嵌套及混合列表、编号、转义、表格/代码不变。既有64项memo块、完整DOM与content-visibility优化保持。
