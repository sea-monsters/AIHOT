# 主题子类卡片阵列

`/topics` 沿用公司 / 机构、领域方向、内容形态三个章节及同一个研究主题读取层。分类、排序、未知项、交叉归属、全部论文和近七日首次收录计数不变，卡片使用服务端提供的真实 `href`。这是主题导航的局部圆角卡片样式；正文与其他页面不恢复大卡片。

- 每节默认两行，CSS 根据可用宽度自动排列，最小列宽 14rem（窄于此时占一整行）。ResizeObserver 读取真实计算后列数，按钮每次加两行；不足两行时显示全部剩余项。
- 三节分别保存行数，窄屏、放大、窗口变化都以当前列数 × 已展开行数重新计算。不同历史条目隔离；同一标签返回主题页恢复原行数，最多保留 48 个章节的布局记录。无本地论文、阅读状态或收藏写入；整页重新载入后布局恢复默认。
- 每节持续显示已显示 / 总子类数。更多按钮标明下一批数量、控制区域及展开状态，键盘激活后焦点移到第一张新增卡片且不主动滚动。收起后焦点回章节标题，仅在必要时就近滚动，避免落在已删除按钮上。
- 长名称完整换行，不截断；零计数明确显示暂无匹配论文。机构的重复来源说明集中放在章节开头，未知项保留自身说明，每张卡片仍提供原定义标题提示。卡片显示近七日新收录篇数。
- 暖橙、纸黄与现有浅深色变量复用；描边和键盘 outline 提示状态，不用阴影、不加内层滚动条。只渲染可见子类卡片，无卡片预取或外部数据请求；展开及收起不改变网址或触发重新读取。

验证：`node --test sites/topic-card-grid.test.mjs` 覆盖列数识别、两行步进、末尾、收起、跨宽度行数和 SSR 结构；整站 typecheck/build、Sites 单测和隔离 Worker/D1 测试覆盖分类与筛选回归。云浏览器检查桌面、窄屏、200% 放大、键盘和返回流程；不触发采集、模型调用或阅读/收藏批量操作。
