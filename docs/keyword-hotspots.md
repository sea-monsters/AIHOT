# 关键词热点分布

`/hot` 的主工作区改为关键词数量与阅读优先级散点图，配套逐篇分数直方图。现有 `/api/site/research/weekly` 仍可读取旧的发表日摘要，未改 AI 任务或采集调度。

## 统计口径

- 默认含今天的近七个 UTC+08 自然日，开始于首日 00:00，截止请求计算时刻。采用首次入库 `first_seen` 或实质元数据更新时间 `updated_at`；反复轮询的 `last_seen` 不算更新。可切换来源发表日或首次入库日。
- `GET /api/site/research/keyword-map` 单次 SQL 查询读取全部窗口记录，使用更新时间与首次入库时间索引。没有 LIMIT 500、Top-N 或客户端分页截断；后端只返回统计需要的论文字段，不返回摘要全文或模型设置。返回 contentRevision 供内容更新提示读取。
- DOI 规范化去重，其次规范原文 URL；同一论文中窄义别名只计一次。题名相同但 DOI 不同不盲目合并。现有 priority=-1 非研究审计记录明确排除，缺失/0 分不排除；无关键词的论文保留未分类。
- 作者关键词全部保留；仅当前内容、模型配置、schema 匹配且摘要引文可核实的已存 AI 关键词参与。规则词典细分 FeFET/铁电、RRAM/忆阻器等不同概念，不把上位概念和器件等同。来源在列表/浮层标注。
- 默认规则阅读优先级沿用当前已存规则分（0–100），没有改评分标准。独立 AI 模式使用已存 importanceScore，不混入规则分；未评分单列。两者均不是科学影响力或经全文核实的质量。
- 散点 x=唯一论文篇数，默认明确标注对数刻度、可切线性；y=已评分论文中位数，0–100 固定；竖线=P25–P75。悬停/焦点展示全范围、已评分分母、缺失数与窗口内真正发表数。JIF 不参与坐标，只在论文参考资料保留带年度官方来源。
- 直方图对全窗口每篇论文只计一次，10 分为箱宽（左含右不含，末箱含100），缺失单列。选关键词时强调关联论文、淡化其他论文，占比共用 0–100% 轴、各组独立分母明确标注，柱顶保留实际篇数；不截取样本。

## 交互与可访问性

右侧保留既有 280px sticky 控制栏（宽屏），窄屏折叠。统计口径默认收起，优先露出关键词列表。关键词完整列表可搜索/滚动，搜索不影响图表聚合。图点和列表支持悬停、Tab 焦点、点击/Enter/Space 固定、Esc/重置解除；触控可直接固定。相同坐标的关键词可从列表逐一选取。数据表是完整的无分页替代入口。展开论文列表可核对所有关联题名、分数依据、日期和原文，沿用已读/收藏组件。打开页面不改已读状态。

## 验证

离线域测试覆盖 UTC+08 边界、三种日期依据、仅轮询触达、DOI/URL 重复、别名、不同概念、1501 条全量覆盖、0/缺失评分、AI 引文失效及分位数。隔离 Worker/D1 测试覆盖新增索引、超过500条窗口全量 API 与 SSR、只读性和零外部调用。完整 Sites、前端和类型/构建回归沿用仓库流程。浏览器检查桌面/窄屏、关键词联动/固定/重置、AI 未评分、数据表与原文入口。
