# 日报采集与证据修复（2026-10-05）

## 语义版本与来源日

学术 API 的「补缺」现在以一个 D1 事务提交缺失字段、语义/元数据哈希、版本和来源证据。摘要或准确发表日期等实际分析输入改变后，旧评估不再被误认为当前内容的结果；只补作者、单位和文献类型不改变 AI 语义哈希。重复操作不会触发模型。当前模型调用配额、未知收费请求不自动重试的规则不变。

同日、午夜截止前、尚未保存日报的候选快照可以更新；判断使用服务器执行补缺的时间，不借用旧缓存的检索时间。首次入库日、原始 run、已冻结归档保持不变。新手动导入记录真实 owner_web / owner_api 来源和独立候选分组，batch_key 为空，不伪造定时任务。

采集写入增加版本比较与最多两次本地重读合并，避免陈旧采集结果抹掉并发补缺；这不是外部请求或模型重试。纸面字段、同日快照及变更记录一起提交，失败可回滚。

## 有界可选补充

每源请求继续使用原有75秒时间预算。Crossref页先入库并提交游标，随后保存出版商 RSS，再做有余量的元数据复查和 OpenAlex补充。可选阶段预留收尾时间，未执行项明确记为 time_budget_deferred。补充在 RSS 后重读库内候选，OpenAlex不能覆盖已有真实出版商摘要。

OpenAlex/Semantic Scholar继续通过既有统一网关，共享单并发、每日100次本站上限、持久冷却与权限熔断。429、401/403和超时不扩张额度、不切换凭证或网络、不把补充失败误报为整页丢失。不修改调度、每源2次/slot、全站20页/slot或模型配额。

## 诊断与冻结

规则资格仍为 priority >75。新归档另存全候选和达标候选的摘要覆盖，最低180字符是证据可用性检查，不是科学质量判断。旧归档只从来源日候选快照重建诊断；不改归档数据、不使用后来补到的摘要冒充当时证据，重建数量不一致时不显示为完整统计。

日报计数、受容量限制的候选快照在同一数据库读取中取得。并发冻结时，插入分组必须匹配胜出的归档内容哈希，输家不能追加不同快照的分组。中断后恢复已收到响应，需重验完成状态、拒绝/工具调用和已有摘要引用检查；无新模型请求。

无待生成分组时，模型配置可用性单独报告，不把它当成空日报的执行阻塞。缺摘要、规则未达标、来源覆盖不完整和未知收费结果是不同状态。首页仍读取最近已保存日报，共用原有对话。
