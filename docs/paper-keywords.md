# 论文分类与研究主题

## 前三分类词

所有阅读出口共用 `paperCategories`：作者明确关键词 → 出版商索引词 → OpenAlex 索引关键词 → OpenAlex 主题 → 当前有效已存 AI 摘要词 → 可解释规则词。按来源返回顺序，先清洗与窄同义词去重，再取前三项。不以模型置信度重排；不足三项保留实际数量。拒绝空串、占位词、HTML、URL 和过于宽泛的单独学科名。来源原词、score、记录 URL、查询时间、缺失状态独立保留。

OpenAlex 关键词是机器生成的索引短语；topics 是较宽的机器主题，两者与原作者关键词严格区分。Crossref 的旧 subject 属期刊级 ASJC 且已于2024年移除，不用于假充文章关键词。没有关键词不等于论文无价值。分类不参与规则评分或日报 >75 门槛。

## 统计与浏览

热点按原有近七日窗口读取全部有效论文，DOI/规范URL去重。同篇在同组计一次、最多属于三个细关键词组；组篇数之和可能大于唯一论文分母。未分类继续计入总数、分布、表格和论文列表，只默认不进入散点坐标缩放，可主动显示。关键词筛选适用于全库，RSS/MCP不再错误地仅搜索近周的关键词成员。

研究主题有公司/机构、领域方向、内容形态三章节。单位只使用实际 affiliation 署名，规范化大小写、空白和标点；不同院系/分校不无依据合并，未知单位单列，出版社不是作者机构。领域按标题、摘要、作者词和前三分类词的明确词义匹配。形式与方法分层：journal-article只能证明注册形式，不能证明实验；仿真、实验、数据工具需明确文字线索。多归属、真实计数、空状态使用同一判定函数。所有单位均可展开查看，列表不丢记录。

## 一次性补全与增量

2026-10-05诊断：1879篇有效论文，1455篇未分类（77.43%），作者关键词0篇；754篇有摘要、10篇有效AI摘要评估。7条非研究审计内容保留但排除。

维护任务冻结有效论文ID，稳定顺序每次50篇，以规范化 DOI 精确关联 OpenAlex；不用弱标题匹配。没有DOI/未命中/无词明确保存状态。一次任务最多3000篇、60次请求；并发lease、每批间隔、游标断点。HTTP失败（含429）暂停并呈现错误；不无界重试，不无视Retry-After。每日原17源、UTC+08 8/20、20页总预算与每源2页不变，不创建额外定时任务或付费模型调用。

证据写入只更新 provenance.keywordEvidence 路径，checkedAt与独立revision/updatedAt不改变论文first_seen、updated_at、metadata_revision、批次、已读收藏、摘要或评分。内容hash排除补充索引词，已归档日报不重算。已有正常OpenAlex补缺请求增加 keywords/topics字段，新记录按相同规则保存，已经查询的关键词不会因空响应反复盲补。来源重新入库保留独立证据。
