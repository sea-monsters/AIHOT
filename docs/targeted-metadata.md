# 定向出版页元数据维护

本次变更新增 `primary_only` 模式，供已认证的站主对明确选择的 1–3 条已有论文进行预览及单独执行。该模式只从原始出版页提取显式 DOI，并通过 Crossref 比较身份；不请求付费搜索或模型。没有摘要不阻止补 DOI。证据缺失、冲突、已占用或提交结果不确定时保守停止，不自动合并或重放。

该能力不更改定时任务、来源调用预算或固定执行器。部署代码与实际对论文执行维护是两个独立动作。

隔离验证使用合成响应与本地 Worker/D1；Node/PostgreSQL 完整服务的六项既存 HTTP smoke 失败仍未解决，不能以 Sites 测试替代。
