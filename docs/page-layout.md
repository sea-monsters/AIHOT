# 全站排版框架与验收范围

维护记录：2026-10-05 UTC。基线：Sites v54 / `5136c06`。这是排版与可访问性改动，不改变采集、评分、模型、账户配置、已读或收藏的业务规则。

## 已定位的错位来源

1. 首页右栏原为 310–360px，1100px 开始双栏；筛选/月历为固定 280px，1120px 开始双栏。相同窗口下正文右边界、栏间距和切换时机不同
2. 首页、研究页和信息页分别有 12px、1.2rem、24px 顶部内边距；首页标题又覆盖为 34px，而信息页、更多与其他研究页各有自己的字号
3. 首页助手从页面顶部开始，其他页面右轨在整段标题、统计、导航后开始，起点随内容长度变化
4. 阅读详情、设置与进展页分别另设 960px、880px、1100px 居中宽度；外层最大宽度还依赖窗口高度，改变高度也会改变横向基准
5. 长短页切换时滚动条占位不同，右边界会跳动；旧收藏折叠区另有第二个 h1

这些结论来自当次实际页面截图及源码，不能把首次 SSR 的两张主题卡或收藏加载态当作最终交互结果。初始浏览器审计一度捕获主题/收藏/设置的初始化状态；最终等待实际完成信号后，主题展开与收藏/设置正常工作。没有把这类过早截图当作 CSS 或 hydration 修复。

## 一个框架，明确变体

| 层级 | 唯一职责 |
| --- | --- |
| `PageFrame` | 所有公开路由及错误页共享容器、边距与最大宽度 |
| `PageHeader` | 页面标题、眉题、描述、操作的共同字号/行高/间距，保留原有语义与事件 |
| `PageGrid` | 单栏、首页助手、筛选/月历、文章右轨共用同一轨宽和间距 |
| `ControlReadingLayout` | 标题、右轨、正文三个显式 slot；手机按标题→筛选开关→正文排列 |
| `AdaptiveRail` | 只在右轨完全容得下时 sticky；过长或短视口时随文档滚动，不做筛选/月历内部滚动 |

首页只保留一个 `AIAssistant` 实例，仍在根 shell 原位置；路由切换不通过 key 重建聊天。手机顺序保持品牌/检索→助手输入→日报正文。聊天消息流是允许内部滚动的独立交互区，不能把这个例外套用于月历和筛选。

单栏信息与详情页从同一左基线开始，正文用 86ch 阅读长度限制，不再整页独立居中。详情的返回链接是明确的前导内容；错误页仍可居中提示。旧周/月报仍为空态，不制造可用内容。`/terms`、`/privacy`、`/feedback` 仍是当前版本说明，不借排版拟定法律条款或新增反馈收集。

## 几何与字级 token

- 侧栏 180px；桌面页面边距 28px，手机 16px
- 统一外层最大宽度 1280px，与窗口高度无关
- 统一右轨 320px、列间距 24px；双栏统一在 1120 CSS px 开始
- 手机导航/检索继续使用现有 961px 断点；960px 及以下采用手机间距
- 正文/右轨顶边采用同一 24px sticky offset；手机 16px
- 页面标题 24–32px、1.4 行高、700 字重；章节、正文、辅助文字继续使用现有 reading tokens
- 统计区按实际容器宽度重排为两列，不以整屏宽度猜测正文可用空间
- 根滚动条稳定占位；长标题、URL、证据诊断可换行；标题锚点预留 sticky 间距
- 保留暖橙、纸黄与现有深色 token；主题三章圆角卡片保留；其他正文使用扁平细线，未加入阴影或渐变

主题每章默认两行、每次加两行仍由实际计算网格轨数决定。没有把 SSR 初值硬编码为 8 张；列数随窗口/缩放变化，历史行数、展开焦点逻辑不变。

## 路由覆盖和限制

机器可读的逐路由矩阵见 [page-layout-coverage.json](page-layout-coverage.json)。它包含全部 52 条注册路由的模板、实际实现状态、首轮截图、1440/1180/600高/390/200%验证状态和限制。新增路由若未登记会导致 `page-layout.test.mjs` 失败。

隔离 Worker SSR 对 52 条注册路由逐一请求：可用页检查共享 frame、唯一 main 与唯一 h1；筛选/月历页检查 header slot；动态详情使用合成论文和隔离订阅记录；重定向检查目标；未迁移路由检查错误 shell 或明确 503。所有外部请求被 mock 阻断，SSR 不标记论文已读、不产生模型回执。

首轮线上截图约 1180×757，后段首页诊断为 1188×761；截图保留于当次浏览器审计中。未截图的动态详情不冒充手动验收。设置仅结构/加载态，未读取或传播密钥。

本次执行环境是 portable，没有可用的用户可见本地预览转发工具；未把线上截图称为本地预览。修改后的真实浏览器核查以矩阵最终记录为准。十一个主要路由样本在 1440×750 和 390×560 CSS 视口逐页截图，其他别名、动态详情、未迁移页明确区分为共享模板验证或隔离 SSR，未宣称全路由全尺寸手动验收。

## 最终实测摘要

- 在 1188×761（100%）与 1440×750（80%）上，首页和控制页标题块与右轨都从 y=24 开始，左基线 x=208；右轨统一 320px，列间距 24px
- 390×560 CSS 视口由正常窗口和 150% 缩放得到，所有主要页面左边距 16px，标题在品牌/检索后从同一 y≈99.33 开始。不是物理手机或设备模拟器测试

- 主题 1188 宽为 4 列默认 8 张→展开 16 张；1440 宽为 5 列默认 10 张；590 宽为 2 列 4→8。通过卡片进入对应论文筛选再返回，保留 8 张与滚动位置
