# HKIS 纸张阅读主题

2026-10-02 的阅读优化沿用已有信息结构、收藏/已读和日报归档，集中调整配色与文本阅读。

## 颜色与层级

- 浅色画布 `#f7f1df`，正文阅读面 `#fffcf3`，导航及栏目以米黄色相对色深区分；正文暖棕黑，主操作与选中采用暖橙。
- 深色采用暖炭色画布与纸墨层级，橙色只保留给操作和选中；错误为红色、警告为赭黄、成功为绿色。
- 全站保持无装饰阴影、无渐变。输入框使用独立边界色，键盘焦点采用 outline。
- 站点原有 HKIS 矢量标识仅换色，应用图标从同一矢量重新导出。

## 文字阅读

- 论文列表标题约 17–18px、650 字重、1.5–1.55 行高；摘要约 15–15.5px、1.75 行高，限制过长行宽。
- 详情摘要 16–17px、1.85 行高、最多 78ch；正文与元信息分层，段落间隔独立。长英文题名、DOI 与中英混排允许正常换行。
- 日报段落保留既有结构与引用，在阅读宽度内排版；空状态标题补足字重和正文间距。
- 已读卡片不使用整体透明度，标题/正文维持对比度；收藏保留书签、文字、边界与选中底色。日报引用 h4 同样有已读层级。
- 保留窄侧栏、Logo 下检索、底部 Agent、月历与更新日志折叠。未修改业务行为。

## 验证边界

- 真实站点先查看论文库、进展、日报月历、收藏空态、设置与更新日志，再检查修改后的桌面和手机宽度、浅/深色。
- 为避免改变个人阅读记录，线上视觉检查不打开论文详情、不收藏或批量更改状态；详情、已读/收藏组合、已生成日报和搜索结果使用隔离样例与组件/Worker 测试。云浏览器不允许访问本地预览地址，因此这些样例没有逐像素浏览器验证；样例不会进入线上数据库。
- 线上检查不提交模型、联网搜索或采集请求。当前归档内容以真实数据库为准，空态不能当成已生成日报。
- 共享测试覆盖正文/次级文字/链接在 11 种实色表面上的 4.5:1 对比度，主按钮 4.5:1，表单边界 3:1，以及错误/警告/成功语义对比度；不能据此宣称整站完全符合所有 WCAG 要求。


## 统一月历与筛选右栏（2026-10-03，UTC+08）

- `/daily`、`/changelog`、`/`、`/research`、`/all`、`/hot` 共用 `ControlReadingLayout`。宽度至少 1120px 时正文在第一列，280px 控制栏在右侧；更窄时使用正文上方的可展开面板，避免在左导航仍可见的窄桌面挤成三列。
- 每页只渲染一套控件，不复制桌面 / 手机月历与筛选。收起按钮保持 `aria-expanded` / `aria-controls` 关系，控件默认收起且不进入手机键盘焦点序列；桌面始终展示。最初版本随页面正常滚动；后续吸顶行为见下节。
- 保留日期、月份和年份导航、今日与归档标记、更新类型、日期锚点、独立折叠、GET 查询参数、重置及分页。论文库表单按返回的筛选状态重新挂载，重置或前后导航不会留下旧的输入值。
- 纯前端布局变更，不改变数据库、模型、配额、采集 / 日报调度和已读 / 收藏行为。
- 回归：`node --test sites/control-reading-layout.test.mjs sites/daily-ui.test.mjs sites/surface-calendar.test.mjs sites/changelog.test.ts`，加 Sites 域测试、typecheck、build 及隔离 Worker/D1 烟测。真实线上检查不提交采集、模型、搜索或已读 / 收藏写操作。


## 右栏吸顶与长面板（2026-10-03，UTC+08）

- 同一共享布局在至少 1120px 的桌面启用原生 `position: sticky`，右栏到达距视口顶部 24px 后保持可见，仍受正文布局的底部边界约束；无固定覆盖层、无装饰阴影。桌面没有覆盖正文的固定页头，24px 也避开顶部加载进度条。
- 右栏按视口高度限制最大高度，下面预留既有 120px 页面 / 外壳尾部间距，同时避开回到顶部入口，滚动到底部也不会把高面板推离窗口。筛选或月历组合超出时仅右栏内部自然滚动，保留滚动条、键盘焦点和默认滚轮边界传递，不添加滚动监听、阻止默认事件或焦点陷阱。
- 小于 1120px 时沿用正文上方默认收起的原有面板，不吸顶、不限制高度；仍只渲染一套月历、搜索和筛选，展开状态不因断点切换重置。
- 改动仅限共享 CSS、相应布局回归和本记录；不改动接口、查询参数、模型、采集 / 日报调度或已读 / 收藏数据。


## 连续文本与统一操作（2026-10-03，UTC+08）

- 列表共用连续文本样式：取消每条论文的四边卡片和圆角，改为单条底部分割线。进展、热点、收藏、日报引用与论文库沿用同一 `PaperCardState`，hover / focus-within 只改变纯色背景，不改变尺寸或触发阅读写入。
- `data-selected` 明确表达当前页勾选状态，以暖橙背景和预留的左侧细标记区分；只影响本地选择显示。已读文字维持可读对比度和标签，已收藏按钮保留描边、填充书签与文字。勾选框没有行级跳转事件。
- 文字共用标题 18px / 650 / 1.55、正文 15.5px / 1.8、元信息 13px / 1.65 的语义变量；手机题名 17px。长摘要仍为 16–17px / 1.85，正文约 78–86ch。日期、来源与说明不再依靠整体透明度降级。
- 详情章节、日报关键词段落、日志日期和设置分组以留白及单边细线组织，正文不重复套色块。鼠标悬停仅在支持 hover 的设备启用；键盘焦点独立保留，触屏不依赖悬停。只有操作控件、输入框、月历和弹窗保留适量圆角。
- 设置服务行维持紧凑布局；展开的配置区与字段保留明确边界，错误 / 确认提示保持独立。主次按钮统一 14px 字号，桌面至少 42px、手机至少 44px 高度；不提交服务测试、保存或收费调用来做视觉检查。
- 右栏断点、280px 宽度、24px 吸顶距离、长面板内部滚动、月历单日切换、查询 / 重置 / 分页和独立折叠行为不变。
- 验证以真实页面截图、已登录只读浏览及隔离组件 / Worker / D1 回归为准。详情、已读收藏组合与有内容日报不通过改动线上个人记录来制造测试数据；未实测的视觉状态不算线上验收。
