# HKIS 纸张阅读主题

2026-10-02 的阅读优化沿用已有信息结构、收藏/已读和日报归档，集中调整配色与文本阅读。

## 颜色与层级

- 浅色画布 `#f7f1df`，正文阅读面 `#fffcf3`，导航及栏目以米黄色相对色深区分；正文暖棕黑，主操作与选中采用暖橙。
- 深色采用暖炭色画布与纸墨层级，橙色只保留给操作和选中；错误为红色、警告为赭黄、成功为绿色。
- 全站保持无装饰阴影、无渐变。输入框使用独立边界色，键盘焦点采用 outline。
- 站点原有 HKIS 矢量标识仅换色，应用图标从同一矢量重新导出。

## 文字阅读

- 论文列表标题约 17–18px、650 字重、1.5–1.55 行高；摘要约 15–15.5px、1.75 行高，限制过长行宽。
- 详情摘要 16–17px、1.85 行高、最多 78ch；正文与元信息分层，段落间隔独立。长英文题名、DOI 与中英混排允许正常换行。
- 日报段落保留既有结构与引用，在阅读宽度内排版；空状态标题补足字重和正文间距。
- 已读卡片不使用整体透明度，标题/正文维持对比度；收藏保留书签、文字、边界与选中底色。日报引用 h4 同样有已读层级。
- 保留窄侧栏、Logo 下检索、底部 Agent、月历与更新日志折叠。未修改业务行为。

## 验证边界

- 真实站点先查看论文库、进展、日报月历、收藏空态、设置与更新日志，再检查修改后的桌面和手机宽度、浅/深色。
- 为避免改变个人阅读记录，线上视觉检查不打开论文详情、不收藏或批量更改状态；详情、已读/收藏组合、已生成日报和搜索结果使用隔离样例与组件/Worker 测试。云浏览器不允许访问本地预览地址，因此这些样例没有逐像素浏览器验证；样例不会进入线上数据库。
- 线上检查不提交模型、联网搜索或采集请求。当前归档内容以真实数据库为准，空态不能当成已生成日报。
- 共享测试覆盖正文/次级文字/链接在 11 种实色表面上的 4.5:1 对比度，主按钮 4.5:1，表单边界 3:1，以及错误/警告/成功语义对比度；不能据此宣称整站完全符合所有 WCAG 要求。
