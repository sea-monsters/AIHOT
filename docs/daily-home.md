# 日报首页与 firedot 站内助手

首页 `/` 以最近已保存（date 不晚于 UTC+08 今天）的论文日报为正文；不以当前日期的空查询覆盖上一期归档，也不跳过 incomplete、empty 或其他真实状态。日报日期、来源日和实际保存/结束时间分开，来源日是首次入库批次日，不是论文发表日。`/daily` 保留按日月历；`/research` 保留论文情报与原始论文入口。没有修改入选分数或日报生成规则。首页更新提示随日报归档版本变化；从原论文库版本迁移后，旧的较高已读计数不会掩盖后续日报更新。

桌面默认显示正文与右侧 sticky 对话栏；较窄屏幕采用单列，紧凑输入框直接可见。对话历史可独立滚动，正文与原日期/局部阅读位置不受聊天滚动影响。用户指定的蓝色耳机卡通原图是静态头像，仅按显示尺寸适配，不使用过期签名 URL。站名仍为 HKIS，助手明确使用用户已配置的模型。

全站仅挂载一个 AIAssistant：首页为栏，其他页面为现有对话框。路由切换、收起、侧栏入口共用内存消息与同步发送锁，不创建第二段会话或自动发请求。快捷问题只填输入框，真正请求仅在点击发送或 Ctrl/⌘+Enter 时发起。此功能沿用非流式响应，不声称收起会中止供应商调用或停止计费；失败/未知结果无自动重发。

页面读取不会调用模型、刷新采集或重生成日报。只有用户主动在首页发送时，服务端构造有限的最新归档上下文：最多三个关键词段落，每段三句（每句500字符）和四个论文ID；不注入整库摘要、密钥或用户配置秘密。归档日期/计数/覆盖由服务器确定性展示；科学解释仍须读取真实论文摘要并通过原引用核验。没有引用证据时，模型自由发挥被覆盖为真实归档状态与证据不足说明。

已有 provider 设置、工具 governor（相同参数5次、同工具15次、累计200次）、请求回执、分钟/每日额度、权限、元数据维护队列和设置提案确认均保留。本站对话不等同于外部个人助手后端。

离线回归覆盖 latest 跨月、真实空状态、原图、共享实例、双发保护结构、无模型读取及服务端上下文防客户端伪造。没有用生产模型调用测试 UI。
