# 局部导航与阅读连续性

2026-10-04：保留 React Router 的 SSR 首屏和客户端导航，不改成全页 AJAX 替换，也不保留所有页面的 DOM。左栏、正文标签使用既有路由，公共侧栏和助手仍在根布局。

## 改动

- 论文初始化按修复版本、规则版本和信源配置检查数据库标记。同一数据库对象并发调用合并；成功处理完所有步骤才记录版本。600 / 5000 条的旧数据分批上限不会提前标完成。来源更改或规则版本变化重新初始化，失败可重试。普通读取只核对版本，不反复 upsert 信源。状态 API 不再重复初始化。
- 正文缓存只在当前标签页内存中存在：最多 16 个完整成功内容快照、15 秒有效期；同时保留该快照的 pageUpdate，不把旧正文配上新版本。单次取消、失败、失效后的迟到响应不会写入缓存。路由各自拥有取消信号，不能错误共用 serverLoader。已读、收藏、设置、密钥和登录响应不进入此缓存。
- 论文筛选和翻页的客户端路径把列表与运行状态分开读取，运行状态最多暂存 30 秒 / 2 条。月历最多暂存 6 个月 / 15 秒。
- 月历只切换月份时 URL 正常变化，但不重新加载选中日报。独立轻量接口只读该月归档概要；切日期才加载对应正文。请求中、空月和错误分别显示，错误保留当前日报并允许重试。月份以 URL 为准，返回/前进及快速切月不会被旧响应覆盖。
- 显式刷新清空内容/状态/月历缓存；回到前台、离开可见状态、跨标签 storage 通知及内容变更均失效。统一更新点发现内容版本变化也失效。同一时刻的导航更新状态 GET 合并，但写操作仍有原先的版本保护。
- 正文等待期间保持原内容，向辅助技术标明忙碌。提交筛选与切换日报日期保留文档滚动；浏览器返回/前进继续使用原位置恢复。跨栏目返回保留已提交的 URL 筛选、展开和阅读位置。展示状态最多 20 个位置，不保存未提交输入，也不保留隐藏页面 DOM。

## 不变的安全边界

预取、SSR、缓存写入均不确认页面已读；只有实际可见且成功呈现的对应快照可确认版本。筛选、历史日报不会清除最新概览更新点。论文已读和收藏仍走独立账户 store，不随换栏目改变。私人 HTTP 响应仍 no-store，不加入共享 CDN 缓存。没有新增采集、模型调用、调度或外部请求。

## 验证与计量

新增 reading-cache 与 navigation-performance 单元测试覆盖过期、LRU、错误、取消、旧响应、失效、版本初始化重试与分批积压、月历轻量读取。沿用页面更新点/论文阅读状态/请求取消/日报测试及隔离 Worker/D1 回归。

隔离空 D1、初始化完成后的可重复操作计量（非线上耗时、非速度倍数）：旧版本三次并发初始化执行 63 条 SQL，其中 54 条写语句；新版同一并发组合为 1 条版本读取、0 条写语句。只切月份，旧完整空日报读取执行 3 条 SQL、JSON 823 字节；新月历读取执行 1 条 SQL、JSON 50 字节。实际有论文/有日报、跨区域网络及冷启动的用户耗时必须单独测量，不从这些数字推导提速倍数。

真实站点基线检查确认桌面左栏与日报正文/月历完整显示。隔离浏览器 localhost 页面被环境扩展拦截，未绕过；浏览器线上交互时延和浏览器全自动回归不作为本次测量结论。
