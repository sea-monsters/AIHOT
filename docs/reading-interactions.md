## 唯一交互层

`apps/web/app/interactions.css` 在主题/几何样式之后加载。`components/ui/Interaction.tsx` 提供链接 class、原文外链标记、折叠指示和原生 summary 包装。既有语义组件类作为兼容别名接入；不使用“所有 a 都是按钮”的全局规则。

- 内联引用：细下划线、暖橙文字，保持句子行高和阅读连贯性
- 轻导航：小圆角与细描边；hover/pressed 只改纯色、边框颜色，不改变尺寸或字重
- 原文/来源：低强调的小外链图标，保留链接目标、键盘与新标签行为；论文原文原有已读写入仅在实际点击时触发，hover/focus 不写入
- 论文标题：保留正文标题，hover/focus 的下划线和强调色引导视线，不额外套卡片
- 折叠：原生 details/summary，或带 aria-expanded/aria-controls 的 button；同一小箭头按状态旋转。收起后原表单字段仍在 DOM 中，浏览器隐藏受控区域，保留输入与选中状态
- 动作：共享 hover、focus-visible、pressed、disabled 和 busy 反馈。禁用文字用实色 token，避免整块透明导致难读；处理中保留文字，不增加循环装饰动画

## 运动、触屏和可访问性边界

反馈时间统一 160ms，只有颜色、轻微透明度和小箭头旋转。原 height/grid-rows 折叠动画和共享文字按钮缩放已移除。`prefers-reduced-motion: reduce` 关闭动画、过渡和平滑滚动。不存在 hover 自动展开，触屏按下提供同等反馈；小屏/粗指针的主要轻操作与 summary 使用 44px 最小触控高度。真正正文内联引用不被拉成 44px 按钮。

所有链接、按钮、summary、输入与选择控件保持可见键盘焦点。折叠后焦点仍位于触发按钮；主题增加两行聚焦首张新增卡片、收起聚焦章标题、返回恢复每章行数与现有动态列数逻辑不变。筛选折叠不会丢弃选中字段，长右栏仍使用文档滚动；只有聊天记录保留必要的独立滚动。

共享浅/深主题文字 tokens 在纯色表面上的 4.5:1 检查沿用并重跑。自动化与截图检查不是完整辅助技术合规认证。

- 新增原生 disclosure / source / inline SSR、服务折叠 DOM 和 aria-controls、disabled/busy、motion/reduced-motion、主题分页与原文点击语义、跨页面复用测试
- 52 路由隔离 SSR 检查维持单 main / 单标题 / 共享布局，详情使用合成数据；阻断所有测试外联，检查无已读写入与模型回执
- UI 检查不点击模型测试、采集更新、保存设置、收藏/阅读写入或外部论文原文。热点 pinned/筛选业务逻辑、未读点确认条件、日报 >75 规则与预算不变
- 当前环境为 portable，没有可用受支持的本地浏览器预览通道；不声称本地可视化预览。后续浏览器验证仅在本次原站部署后通过同一云浏览器完成
- 最终测试和浏览器覆盖结果按实际执行补充；未覆盖项目保持明确标记
